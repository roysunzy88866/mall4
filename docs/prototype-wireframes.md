│              │  ┌──────────────────────────────────────────────────────────┐

收货信息为固定假数据(只展示不录入)。**进本页即锁定「下单价快照」**(此后商品改价不影响该单)。

### 4b. 全屏二维码 + 倒计时(点「去支付」后)
```
┌──────────────────────────────────────────────────────────────────────────┐
│                          请扫码支付   ¥39.00                                │
│                       ┌──────────────────┐                                 │

│                       └──────────────────┘                                 │
│                       支付剩余时间  02:59                                    │
│                  ( 点击屏幕任意位置 = 支付成功 · 演示用 )                      │
└──────────────────────────────────────────────────────────────────────────┘
```
