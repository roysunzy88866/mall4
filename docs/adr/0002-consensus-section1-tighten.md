# ADR-0002 · 共识 §1「车机端不存数据」措辞收紧

- **状态**:已采纳(2026-06-03)
- **决策者**:用户(AskUserQuestion 拍板)

## 背景
[需求共识.md](../../需求共识.md) §1 原文:「车机端不存任何数据(订单历史除外:订单为本机已下单记录)」。后端共创定 **D3「订单只存服务器,车机按设备号拉」**,与「订单为本机已下单记录」字面略有出入。

## 决策
把 §1 收紧为:**车机端不本地存任何业务数据,订单也只存服务器,车机仅本地存一个虚拟设备号,订单历史按该设备号从服务器实时拉**。

## 理由
语义未变(仍是「本机的单」),仅澄清「不本地缓存」,与 D3 实现一致,消除断网行为歧义——断网时订单页与其他页一样走「网络异常」,符合共识验收 §5「断网即失败」。

## 影响
- 需求共识.md §1 已改;[后端需求.md §11](../../后端需求.md) 记录。
- 不影响其余验收标准。
